# Predictive Maintenance - RUL Prediction

## 1. Project Overview

End-to-end predictive maintenance system using turbofan engine degradation data.

## 2. Business Problem

Predict Remaining Useful Life (RUL) to optimize maintenance planning and reduce operational risks.

## 3. Project Architecture

- Data ingestion
- Feature engineering
- Model training (XGBoost, LSTM)
- Model evaluation
- Inference API

## 4. Tech Stack

- Python
- Scikit-Learn
- XGBoost
- FastAPI
- Docker (planned)
